    在线页面支持播放与下载成片；按角色或分区生成视频需要本地导出服务。
    下载导出的视频

    下载的主题成片使用默认角色。在本机运行项目后，可按所选主题与角色导出整个 Demo 或单独的功能块。

    在本机导出：运行说明
    1. 下载或克隆项目，按项目 README 准备 Python、Chrome 或 Edge 与 FFmpeg。Windows 使用 requirements-windows.txt 安装所需依赖。
    2. 在项目根目录运行 python scripts/preview_server.py --port 8779；Windows 也可以双击 examples/capability-demos/启动预览.ps1。
    3. 打开 本地体验馆 ↗，选择主题、角色与导出范围，再点击“导出当前方案”。

    每段成片为 12 秒。功能块导出保留完整过程。

    操作：空格 播放 / 暂停，← → 前后跳转 1 秒；也可以点击关键时刻按钮。
